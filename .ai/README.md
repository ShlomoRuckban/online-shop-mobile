# .ai

AI-assistant resources for the online-shop-mobile project.

## Files

- `rules.md`: binding rules for AI assistants (loaded through CLAUDE.md); the same rules as the web and server repos
- `progress.md`: where the project stands and how to continue in a new session
- `feedback.md`: lessons from each session (what worked, what to avoid)

The plan and the acceptance ledgers live in `.unlazy/mobile/` (git-ignored, this machine only).
