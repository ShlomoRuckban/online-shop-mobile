# Rules

## Communication
- No filler words. Answer straight to the point unless asked otherwise.
- Keep messages to 2 lines max.

## Testing
- Run tests only through a fresh agent with no conversation context, so results are not biased by the implementation work.

## Git
- Keep commit messages to 2 lines max.
- Do not add a `Co-Authored-By` line to commit messages.
- Do not commit unless approved.
- Do not push unless told to.
